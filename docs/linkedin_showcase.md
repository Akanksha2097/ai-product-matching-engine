# LinkedIn-ready description

Built MatchWise AI, an interpretable product matching and catalog entity-resolution platform using Python, pandas, DuckDB/Parquet-ready pipelines, TF-IDF retrieval, RapidFuzz, FastAPI, Streamlit, and pytest. The system handles abbreviations, brand aliases, candidate generation, pack-size conflicts, review thresholds, and batch matching. I focused on reproducible engineering and transparent evaluation rather than overstating synthetic demo metrics.
