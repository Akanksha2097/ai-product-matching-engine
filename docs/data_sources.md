# Data sources and provenance

`data/demo/catalog.csv` is a tiny synthetic offline fixture designed for deterministic tests; it is not benchmark ground truth. `data/demo/openfoodfacts.csv` is a small real product sample fetched from Open Food Facts on 2026-11-04. Do not treat these catalogs as linked or use one to label the other.

The public ingestion source is [Open Food Facts](https://openfoodfacts.github.io/openfoodfacts-server/api/). Its database is licensed under [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), with individual contents under DbCL. The included product sample is attributed to Open Food Facts contributors and is shared under ODbL 1.0, separately from the repository's MIT-licensed source code. The sample has no product images. The ingestion helper uses a custom User-Agent, one bounded page, backoff, and a local Parquet cache. Open Food Facts documents its [API conditions](https://support.openfoodfacts.org/help/en-gb/12-donnees-api/94-y-a-t-il-des-conditions-pour-utiliser-l-api).

For labeled entity-resolution evaluation, we downloaded the published [DeepMatcher Abt–Buy dataset](https://github.com/anhaidgroup/deepmatcher/blob/master/Datasets.md) from the [University of Wisconsin hosted files](https://pages.cs.wisc.edu/~anhai/data1/deepmatcher_data/Textual/Abt-Buy/exp_data/). The 9,575 published pair labels are benchmark labels, not Open Food Facts labels. Source CSVs are excluded from Git because the source page does not state clear redistribution terms; the repository publishes only code and aggregate metrics. To reproduce, download `tableA.csv`, `tableB.csv`, `train.csv`, `valid.csv`, and `test.csv` into `data/raw/abt_buy/`, then run `python scripts/evaluate_benchmark.py`.
